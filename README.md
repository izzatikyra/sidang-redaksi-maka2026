# Sidang Redaksi Moments Photography — MAKA 2026

Next.js starter for the MAKA 2026 photography website.

## Setup
1. Run `npm install`.
2. Copy `.env.example` to `.env.local`.
3. Add the Supabase project URL and anon/publishable key.
4. Run `npm run dev`.

This is a starter landing page only. Gallery search, checkout, secure uploads, payment proof handling, and staff dashboard must be implemented and tested before production. Never expose a Supabase service-role key in client-side code.
